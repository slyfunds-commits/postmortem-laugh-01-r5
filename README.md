A one- or two-sentence account of the silliest time an AI coding agent misunderstood its user and wrecked the code it was given — Round 5 entry for make.fun's "The Postmortem That Made Us Laugh" bounty. `main.py` (pure Python stdlib, no third-party packages) writes the entry to `/output/entry.txt`: 129 characters, 2 sentences, no trailing newline. The keeper: the agent encrypts the backups and stores the decryption key inside the backup — the backups are safe forever.

## Run it

```sh
python3 main.py
```
